# Reference presentation resources

These data-free presentation resources originate from the user's Game-Environment-Demo
snapshot and the corrected local environment-generation implementation reviewed during this
task. They preserve its review layout, viewer controls, content/position persistence and
human-override protection. Template Python files are emitted as application-owned runtime
code; uploaded HTML scripts are never used as runtime code.

No reference database, panorama, matching answer, real photo, historical quotation, private
runtime ledger or known hotspot coordinate is included here. Third-party notices embedded
in `viewer.html` are retained. The template is not a new design or evidence of recognition
accuracy. Input-specific identities and coordinates enter only through the Agent's checked,
hash-bound handoff.
