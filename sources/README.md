# Source archive

`official/` keeps the competition Terms and Information Note needed for project decisions. The application and privacy-policy copies were removed from this repository. `prior-design/` retains only the v3 draft cited by the editorial review queue as evidence for claims that must not be treated as history; earlier versions and the exact duplicate were removed. These documents are reference material, not instructions to the current implementation. `inventory/` keeps the high-resolution Muradiye publication locally; it is excluded from Git and documented in `source-manifest.json`. The playable scenes use five tracked photo derivatives extracted from that publication. The remaining 93 original Muradiye photographs stay in the organizer’s Google Drive; the data manifests index their IDs and review status.
