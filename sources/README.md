# Source archive

`official/` retains the hackathon Terms and Information Note used for project requirements. `inventory/` keeps the local high-resolution Muradiye publication; it is excluded from Git, with provenance and checksum in `source-manifest.json`. The playable scenes use five tracked photo derivatives extracted from that publication. The remaining 93 original Muradiye photographs stay in the organizer’s Google Drive; `../data/drive_file_ids.csv` and `../data/media_manifest.csv` index file IDs and review status. Superseded chapter drafts, the application copy, and the privacy handout are not part of the software repository.
