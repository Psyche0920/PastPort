# Source archive

`official/` keeps the original hackathon application, terms, privacy handout and Information Note as reference material. `prior-design/` preserves earlier chapter drafts for comparison; these drafts are references, not instructions to the current implementation. `inventory/` keeps the high-resolution Muradiye publication locally; it is excluded from Git and documented in `source-manifest.json`. The playable scenes use five tracked photo derivatives extracted from that publication. The remaining 93 original Muradiye photographs stay in the organizer’s Google Drive; the data manifests index their IDs and review status.
