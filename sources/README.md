# Source archive

Reference PDFs are kept as read-only source material. `official/` contains hackathon and application documents, `inventory/` contains the Muradiye inventory volume, and `prior-design/` preserves earlier PastPort chapter drafts for comparison. The 93 high-resolution Muradiye photographs remain in the organizer's Google Drive; `../data/drive_file_ids.csv` indexes their stable file IDs and `../data/media_manifest.csv` records review and mapping status.
