# 最后两袋 · Muradiye 章节 v2

## 玩家要解决的问题

1430 年代的原创情境。优素福刚获准担任试任文书员，学徒杰姆是他的担保人。供餐前，正式账写着麦粒十二袋，粮仓却只有十袋。管事怀疑搬运货物的杰姆。主角可以顺着怀疑保住职位，也可以在交账前查清去向；最后发现，他把混合货物的总数误写成了单一麦粒数。

人物、账单、数量、证词、会面和处置均为原创，不是 Muradiye 历史事件。真实依据只包括遗址身份、构件、制度中的记录/保管/厨房职责和供餐背景。当代照片是观察窗口，绝非 1430 年代视觉复原。后期玻璃顶、招牌、管件与餐厅家具均明确排除出历史证据。

## 公平的证据链

开场原账即出现“送达十二袋货物”“誊写麦粒十二袋”“品类待核”。玩家无需等到最后才有机会发现分类疑点。装车单提供十袋麦粒与两袋面粉；厨房收料单证明两袋面粉已到；粮仓清点仍为十袋。数量闭合并不自动证明送货者身份，哈丽梅的具名证词承担第二条证据链。

任何选择都不能改写这些数量和历史属性。保护杰姆只改变他是否继续同行；是否帮助哈丽梅改变具名证词能否获得；最终落笔决定原账是否可追溯、学徒核验、主角试任资格和供餐后果。

## 选择造成的实际变化

- 担保：两刻钟、担保责任，杰姆留下；拘留：节省时间，杰姆离开，后续对话改变，关系伤害保留。
- 帮助证人：两刻钟、获得具名证词，证人同行；赶路：没有具名证词，厨房收料单的送货者栏仍为空。
- 署名更正：一刻钟，独立签账资格暂停；有证词可撤回学徒嫌疑，无证词只能解释数量、保留身份核验。
- 抽走原账：职位暂时保住，错误来源不可追溯，学徒仍被追问。
- 推责厨房：核查厨房人员并暂停这次虚构供餐。

六刻钟为故事内的交账时限，不使用现实倒计时。担保、帮助、厨房核账和署名更正累计七刻钟，会造成一餐延后；该后果在最后落笔之前即可预见。时间不足不阻断游戏，玩家必须承担延迟。

## 复用框架

`人物欲望 → 个人责任形成的冲突 → 可见构件支持地点/功能辨认 → 取得明确标为虚构的案情证据 → 有成本的人际选择 → 多处记录或证据交叉核对 → 承担/掩盖/转嫁责任 → 关系、服务与成长结果`。

新遗址需要替换照片、可见属性、制度背景、主角责任和证据链，不能把同一谜题原封不动换地名。事实和照片定位需要先批准；任务默认使用经审核的固定版，人工发布覆盖优先。运行时 AI 出题仍未接入。
