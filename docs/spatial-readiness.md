# Muradiye Spatial Readiness

## What the sources support

The inventory’s printed pages 111–170 cover the mosque, madrasa, fountain, imaret, bathhouse, and thirteen tombs. They provide relative positions, selected dimensions, descriptions, inscriptions, and publication photographs. This is enough for a sourced catalogue, narrative route, and schematic 2D map.

| Place | Supported prototype | Still needed for an accurate model |
|---|---|---|
| Mosque | 2D map marker and photo-based observations | Surveyed plans, sections, dimensions, and continuous interior coverage |
| Madrasa | Schematic courtyard and low-detail room concept | Room-by-room dimensions, openings, and verified current plans |
| Fountain | Feature inspection task and simple object concept | Confirmed photo match and measured elevation |
| Imaret | Relative location, exterior massing, and evidence cards | Interior measurements, entrances, and surveyed plans |
| Bathhouse | Location and room-sequence diagram | Measurements, roof and pipe survey, and accessible interior imagery |
| Tombs | Catalogue and selected visual details | Precise coordinates, individual surveys, and verified sarcophagus identities |

## Practical limits

Online 2D clue-finding is supported by the current evidence. The map shows relative position, not navigation. GPS stays off until coordinates, radius, and consent behavior are reviewed on site.

A concept-level interior 3D scene can be built from described spaces, but it must label inferred geometry as a reconstruction. AI-generated fill is an art assumption, not historical evidence or survey-accurate pathfinding. One photograph cannot recover a complete interior. Photogrammetry needs overlapping views, camera data, and a scale reference.

## Staged workflow

1. Review the building relationships, source links, confidence, and photo matches in a 2D layer.
2. Complete the publication-page to filename to building crosswalk for each playable node.
3. Verify coordinates and access rules on site before enabling GPS tasks.
4. Build exterior low-detail models first, then rooms supported by measured evidence. Label surveyed, evidence-based, and artistic elements separately.

The database reserves GPS, geometry-state, and model-asset fields. They do not affect the current game.
