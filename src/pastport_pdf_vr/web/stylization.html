How usage limits work

Recorded tokens include image and context usage; this is not a currency quote. Estimates include a repair reserve; unused calls are not dispatched. Review-token allowances are planning estimates, not measured billing. The token threshold is checked before each model call, so one call may exceed it. The agent compares results with the approved sample. Severe defects may trigger one repair round; otherwise it passes without repainting. Never a second repair or automatic budget increase.

Supported files and current limitations

Labelled PastPort VR exports and complete native 3D tour packages with clean source panoramas. The agent accepts up to 6 viewpoints per bounded job; full 2:1 panoramas up to 4096 × 2048, and supported SPZ v2 assets. Other vendor formats and standalone meshes require an adapter.

Output remains a candidate for your review. This version changes appearance; it does not fix missing or incorrect 3D geometry.
